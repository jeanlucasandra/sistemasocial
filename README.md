# sistemasocial
sistema básico de vida social feito inteiramente em Java (Intellij IDEA).

Sistema de vida social que envolve 4 funções claras:

1-Cadastro pessoal;
2-Menu de academia (envolve sistema de peso);
3-Menu de alimentação (envolve sistema de saúde);
4-Revisão da ficha pessoal durante desenvolvimento;

Valor de peso perdido ou ganho, e saúde perdida ou ganha é totalmente
randomizado. NÃO HÁ PADRÃO DE VALORES.

Opcão de encerrar programa inclusa.
